# Sightline

A local-first library for collecting website inspiration, screenshots, videos, and fonts.

## Install Sightline

1. Download `Sightline_<version>_x64-setup.exe` from [GitHub Releases](https://github.com/Hosea174/sightline/releases/latest) and run it.
2. If Windows SmartScreen appears, select **More info → Run anyway**.
3. Open Sightline and choose a folder for your library.

Sightline checks for the tools it needs and can install missing ones automatically. It also checks for app updates.

## Set up the Chrome extension

1. In Sightline, click the puzzle icon to open **Browser extension & tools**.
2. Click **Open extension folder**. Keep that folder open.
3. In Chrome, go to `chrome://extensions` and enable **Developer mode**.
4. Click **Load unpacked** and select the extension folder.
5. Back in Sightline, click **Detect**, then select the Chrome entry to connect it. If it doesn't appear, copy the extension ID from `chrome://extensions`, paste it into Sightline, and click **Connect**.

You can now use the Sightline extension to capture content from Chrome. The extension folder is refreshed when Sightline updates.

Your library is stored in the folder you chose. Back up that folder separately to keep a copy of your saved work.
